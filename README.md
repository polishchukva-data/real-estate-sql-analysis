## SQL Analysis

The project includes two analytical cases:

### 1. Listing Activity Duration

Analyzed:
- listing lifetime segments;
- property characteristics affecting sales speed;
- regional differences between Saint Petersburg and Leningrad Region.

### 2. Seasonal Market Trends

Analyzed:
- monthly publication activity;
- monthly removed listings;
- price per square meter dynamics;
- seasonal changes in property area.
